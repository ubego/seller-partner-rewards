# Ubego Seller Partner Reward Calculator

Single Page Application (SPA) для расчета вознаграждения продавцов-партнеров Ubego.

## Технологии

- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion
- **Icons**: Lucide React

## Запуск

1. Установите зависимости:
   ```bash
   npm install
   ```

2. Запустите сервер разработки:
   ```bash
   npm run dev
   ```

3. Откройте [http://localhost:3000](http://localhost:3000) в браузере.

## Функциональность

- **Входные данные**: Плановые и фактические показатели (Встречи, Подписания, Запуски) + Базовый оклад.
- **Расчет вознаграждения**: 
  - **Выплата за встречи**: 300 ₽ за каждую встречу.
  - **Бонус за KPI по встречам**: 700 ₽ за встречу (если план выполнен).
  - **Выплата за подписание**: 5 000 ₽ за договор.
  - **Бонус за KPI по подписаниям**: 2 000 ₽ за договор (если план выполнен).
  - **Выплата за запуск**: 20 000 ₽ за запуск.
  - **Бонус за KPI по запускам**: 5 000 ₽ за запуск (если план выполнен).
- **Интерактивность**:
  - Мгновенный пересчет при изменении ввода.
  - Подсказки (Tooltip) с формулами расчета.
  - Подсветка выполненных KPI.
- **Интерфейс**:
  - Адаптивный дизайн (Mobile/Desktop).
  - Анимации UI при взаимодействии.
- **Технические особенности**:
  - Полностью статический пререндеринг (SSG).
