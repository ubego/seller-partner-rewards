# Ubego Seller Partner Reward Calculator

Single Page Application (SPA) для расчета вознаграждения продавцов-партнеров Ubego.

## Технологии

- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion
- **Icons**: Lucide React

## Запуск

1. Установите зависимости:
   ```bash
   npm install
   ```

2. Запустите сервер разработки:
   ```bash
   npm run dev
   ```

3. Откройте [http://localhost:3000](http://localhost:3000) в браузере.

## Функциональность

- Расчет Base Salary + Meeting Reward + KPI + Sign Reward + KPI + Launch Reward + KPI
- Интерактивный интерфейс с подсказками (Tooltip)
- Анимации UI
- Полностью статический пререндеринг (SSG)
