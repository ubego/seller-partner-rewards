# Ubego Seller Partner Reward Calculator

Single Page Application (SPA) для расчета вознаграждения seller manager Ubego.

## Технологии

- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion
- **Icons**: Lucide React

## Запуск

1. Установите зависимости:
   ```bash
   npm install
   ```

2. Запустите сервер разработки:
   ```bash
   npm run dev
   ```

3. Откройте [http://localhost:3000](http://localhost:3000) в браузере.

## Функциональность

Норма для full-time: **12 квалифицированных встреч → 3 пилотных договора → 2 полных договора**.

Договоры и запуски считаются двумя независимыми треками и суммируются.

- **Квалифицированная встреча**: 3 000 ₽ × коэффициент KPI.
- **Бонус за выполнение плана встреч**: 10 000 ₽, если факт ≥ плана.
- **Пилотный договор**: 10 000 ₽ × коэффициент KPI.
- **Полный договор**: 20 000 ₽ × коэффициент KPI.
- **Пилотный запуск**: 3 000 ₽, без KPI.
- **Полный коммерческий запуск**: 20 000 ₽, без KPI.

Коэффициент KPI (каждый показатель независимо):

| Выполнение | Коэффициент |
| ---------- | ----------: |
| ниже 51%   |       ×0,80 |
| 51–99%     |       ×1,00 |
| 100–149%   |       ×1,30 |
| 150–199%   |       ×1,45 |
| 200%+      |       ×1,57 |

Ровно 50% — недовыполнение (×0,80). Выполнение плана (100%) — ×1,30.

Прямой полный договор учитывается и в пилотном, и в полном KPI. Прямой полный коммерческий запуск выплачивает обе ещё не оплаченные части запуска: **3 000 ₽ + 20 000 ₽ = 23 000 ₽**.

Стандартный сценарий (12 / 3 / 3 / 2 / 2) даёт **196 800 ₽**.
